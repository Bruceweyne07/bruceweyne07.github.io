# recetas

Página web de recetas de cocina españolas y caseras: **La Alacena**.

Web de recetas españolas caseras: inicio con recetas destacadas, categorías (entrantes, platos principales, postres y vegetariano), página de cada receta con ingredientes ajustables por raciones y pasos numerados, buscador y contacto.

Es una página estática: abre `index.html` en el navegador o publícala con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).

## Estructura

- `index.html`: toda la web (HTML, CSS y JavaScript).
- `fotos/`: fotos de las recetas en dos tamaños (`nombre.jpg` grande y `nombre-p.jpg` para tarjetas).

## Fotos

Las fotos son de [Pexels](https://www.pexels.com) y se usan bajo la [licencia de Pexels](https://www.pexels.com/license/), que permite el uso gratuito sin atribución obligatoria. Cada receta enlaza a su foto original.

## Formulario de contacto

El formulario valida los campos pero no envía mensajes. Para recibirlos hay que conectarlo a un servicio como Formspree o Netlify Forms.
